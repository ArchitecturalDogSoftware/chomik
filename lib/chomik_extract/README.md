# `chomik_extract`

`chomik_extract` is the crate used by `chomik` to extract images and XML files from the `.anim` files
embedded within a [ChomikBox](https://chomikuj.pl/chomikbox) MSI file.

An example of how to use `chomik_extract` can be found in [`examples/extract.rs`](./examples/extract.rs).
